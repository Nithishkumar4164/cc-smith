# cc-smith

AI agent that recommends credit cards from your category-wise spends, tells you which card to use for each purchase, how to acquire new cards, and delivers news that affects your stack.

- Market: India
- Audience: public product
- Surface: Flutter app (iOS + Android) over a backend API
- Status: ideation — see [docs/ideation.md](docs/ideation.md), [docs/features.md](docs/features.md) (consolidated feature list), [docs/prd.md](docs/prd.md) (PRD), [docs/user-stories.md](docs/user-stories.md) (user stories), [docs/decisions.md](docs/decisions.md) (decisions log), [docs/stack.md](docs/stack.md) (stack), [docs/research/](docs/research/) (community pain-point sweeps)
